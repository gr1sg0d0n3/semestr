# Страница и ролики «Наш дом»

Публичная страница проекта и анимированный показ его трёх частей: сайт, бот, мониторинг сервера.
Сделано по правилам скиллов `landing-page-design` и `design-to-motion`.

| Файл | Что это |
|---|---|
| `index.html` | Одностраничный лендинг. Открывается как файл или с любого статического хостинга |
| `bento.js`, `bento.css` | Три анимированные карточки. Один код для страницы и для роликов |
| `showcase.html` | Сцена 1440×810 для записи. `?still` финальный кадр, `?loop` цикл 12 с, `?capture` время ведёт рекордер |
| `media/` | `nashdom-x.mp4` (1920×1080, 60 к/с), `nashdom-loop.gif` (960 px), `nashdom-800x500.gif`, `og.png` |
| `tools/record.js`, `tools/encode.sh` | Покадровая запись и кодирование |

## Пересобрать ролики

```bash
python3 -m http.server 8766          # из корня репозитория, в другом окне
cd promo/tools
node record.js /tmp/frames           # нужны Node, playwright и Chromium
./encode.sh /tmp/frames ../media     # нужен ffmpeg
```

Запись не идёт в реальном времени: страница получает шаги по целым миллисекундам (в среднем 1000/60),
поэтому цикл замыкается без шва. Проверено: первый кадр цикла равен кадру через 12 секунд,
кадры «пустой паузы» равны кадру до старта, кадр покоя равен `?still`.

## Шрифт

Скилл разрешает Geist, Manrope или Poppins, а кириллица есть только у Manrope. Файлов шрифта в репозитории пока нет,
поэтому используется токен `--font` (`'Manrope', system-ui, ...`). Когда положите Manrope (woff2, веса 400, 500, 600, 700)
в `nash-dom/fonts/` и `promo/fonts/`, добавьте `@font-face` в `nash-dom/css/app.css` и `promo/bento.css`
и пересоберите ролики. Файлы шрифта подхватит сервис-воркер сайта при первой загрузке.
