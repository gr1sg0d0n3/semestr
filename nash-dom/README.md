# Наш дом
Семейный сайт на двоих: учёба, хотелки, кино, места, меню и т.д. Всё добавляется, правится и удаляется; данные хранятся в браузере (localStorage), есть экспорт/импорт JSON. Статика, без сборки — открыть index.html или выложить на любой хостинг/GitHub Pages. PWA (добавляется на экран iPhone).
